# Ejercicio 04 - Pantalla de acceso

## Qué he aprendido
- A usar el secureTextEntry.

## Respuesta a la pregunta de comprensión
¿Por qué en este ejercicio no necesitamos todavía `useState`?

Respuesta:
No necesitamos `useState` porque en este ejercicio solo estamos creando la apariencia de la pantalla y todavía no necesitamos guardar ni modificar ningún dato. Aunque haya campos de texto y un botón, no estamos haciendo nada con lo que el usuario introduce o pulsa.

## Qué he modificado
- He añadido debajo del botón un texto centrado: “¿No tienes cuenta? Regístrate”.

## Resultado
La interfaz ha quedado como una pantalla de inicio de sesión sencilla, con un título de bienvenida, campos para el correo y la contraseña, un botón azul para iniciar sesión y un "enlace" para registrarse.
