# Ejercicio 02 - Tarjeta de bienvenida

## Qué he aprendido
- He aprendido la diferencia entre `padding`y `margin`

## Respuesta a la pregunta de comprensión
¿Por qué usarías `padding` en una tarjeta en lugar de `margin` para separar el texto del borde?

Respuesta:
Usaría `padding` porque crea espacio interno entre el contenido y el borde de la tarjeta, mientras que `margin` separa la tarjeta de otros elementos externos.
