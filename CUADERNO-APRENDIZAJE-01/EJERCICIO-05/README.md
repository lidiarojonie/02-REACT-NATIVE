# Ejercicio 05 - Tarjeta de producto

## Qué he aprendido
- Como resaltar una etiqueta.

## Respuesta a la pregunta de comprensión
¿Qué información debería tener mayor jerarquía visual: categoría, nombre del producto o precio? Justifica tu decisión.

Respuesta:
El nombre del producto debería tener mayor jerarquía visual, porque es la información principal que permite identificar rápidamente qué se está mostrando, mientras que la categoría sirve para contextualizarlo y el precio para conocer su coste.

## Qué he modificado
- He añadido y dado estilos una etiqueta de "OFERTA".

## Resultado
La interfaz ha quedado como una tarjeta de producto moderna, con una imagen superior, la categoría y una etiqueta de oferta, seguida del nombre, la valoración, el precio y un botón destacado para añadir el producto.
