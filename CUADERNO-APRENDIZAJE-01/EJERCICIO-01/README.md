# Ejercicio 01 - Mi primera pantalla

## Qué he aprendido
- He aprendido la diferencia entre `View` y `Text`

## Respuesta a la pregunta de comprensión
Explica con tus palabras la diferencia entre el componente `View` y el componente `Text`.

Respuesta:
`View` se utiliza para organizar y contener elementos, mientras que `Text` se utiliza para mostrar texto en la pantalla.
